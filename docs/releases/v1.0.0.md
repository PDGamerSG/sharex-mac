The first public release of ShareX Mac: a native menu-bar screenshot app with offline OCR and local image history.

## Download and install

Download **ShareXMac-universal.zip** below, extract it, and move **ShareX Mac.app** to **Applications**. Requires **macOS 13+**; the same download supports **Apple Silicon and Intel**. Quit any older running copy before replacing it.

Choose a screenshot folder on first launch and allow the app under **System Settings → Privacy & Security → Screen Recording** (or **Screen & System Audio Recording**), then reopen it if macOS requests it.

This build is **ad-hoc signed, not Apple-notarized**. If macOS blocks the first launch, attempt to open the app, then use **Privacy & Security → Open Anyway**.

## Default shortcuts and fixes

- **Option-P (⌥P):** capture a selected region.
- **Shift-P (⇧P):** recognize text in a selected region.
- **Escape:** cancel capture selection or countdown.
- Fixed shortcut validation so Shift-only combinations can be recorded, saved, and registered.
- Fresh installs use the defaults above. Existing installations retain saved bindings; **Settings → Hotkeys → Reset all shortcuts** restores the new defaults.

## Included features

- **Screen capture:** all connected displays in one image, selected regions (including across displays), and a click-to-select window picker.
- **Image quality:** lossless PNG, full Retina resolution by default, optional 75% or 50% dimensions, and full-resolution OCR captures.
- **Capture controls:** include/hide the cursor and a cancellable 0–60 second delay.
- **Clipboard:** automatically copy successful screenshots, disable automatic copying in Settings, or copy a saved image from Image History.
- **Save confirmation:** a brief corner notification with an Open Folder action to reveal the screenshot in Finder.
- **Offline OCR:** Apple Vision recognition from a region or saved screenshot; editable results, multiline/single-line output, retry, and copy text.
- **OCR settings:** automatic language detection or selected supported languages, language correction, and 1×–4× recognition scale.
- **Image History:** local thumbnail grid, filename search, dimensions and dates, refresh and missing-file status, preview, open, reveal in Finder, copy image/path, OCR, and confirmed deletion of the file and history entry.
- **Global hotkeys:** customizable bindings for all capture modes, OCR, Image History, and Settings; clear/reset controls, duplicate detection, registration-error reporting, and shortcut labels in the menu bar.
- **Storage:** a configurable screenshot folder with remembered access, collision-safe filenames, local SQLite history, and folder/database status in Settings.
- **Startup and permissions:** launch at login, start hidden in the menu bar, and direct links to macOS privacy settings.
- **Local operation:** no accounts, uploads, or network services. GPLv3-licensed; an independent, unofficial implementation of this ShareX feature subset.
