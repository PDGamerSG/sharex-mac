New screenshots are organized into monthly folders, and single-key and media-mode function-key shortcuts are supported.

## Changes

- Screenshots save in `YYYY-MM` folders inside the selected screenshot folder, for example `~/Pictures/ShareX/2026-11`. The local capture date determines the folder, including across month and year changes. Existing screenshots stay in place.
- Single keys such as A, P, and F9 can be assigned as global shortcuts.
- Fixed the shortcut recorder staying on “Type shortcut…” when Option-F9 sends a media-control event. Record the keys exactly as you will use them; media-mode shortcuts may need Accessibility access, with a link shown if registration fails.
- Media shortcuts fire once per press and leave unrelated media keys available for their normal actions.
- Image History, clipboard copies, and Open Folder use the PNG's monthly location.

## Install

Download **ShareXMac-universal.zip**, quit the running app, extract the ZIP, and replace **ShareX Mac.app** in **Applications**. Existing settings and history are preserved. Requires **macOS 13+**, on Apple Silicon or Intel.

The app is ad-hoc signed and is not Apple-notarized. See the [installation instructions](https://github.com/PDGamerSG/sharex-mac#install) if macOS blocks its first launch.
